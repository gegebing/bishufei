# 毕数飞行平台 · C端小程序 UI 设计规范(交付概述)

## 本次完成
依据《毕数飞行平台系统设计方案 V2.0 最新版》,产出了面向开发团队、聚焦 C 端微信小程序的 UI 设计规范文档。

**主交付物**:`毕数飞行平台_C端小程序UI设计规范.md`

## 规范覆盖内容
1. **设计理念与原则** — 专业可信、任务驱动、合规显性化、一致性优先。
2. **设计基础 token** — 品牌色(天空蓝 #1677FF × 活力橙 #FF7A00)、功能色、中性色、字体阶梯、4px 间距、圆角、阴影、图标、rpx 单位换算。
3. **全局布局** — 页面骨架、5 项 TabBar、安全区、加载/空/错误/弱网四态。
4. **组件库** — 按钮、标签/徽章、订单卡片、列表、表单、反馈、合规引导组件、数据展示。
5. **核心页面** — 首页、订单广场/需求发布、订单详情与履约、学习中心、商城、个人中心。
6. **关键交互流程** — 接单、发单、培训报名、CAAC 考证报名、UOM「一登二查三申请」合规引导。
7. **开发落地** — SCSS 变量速查表 + uni-app 使用要点。

## 关键设计决策
- 品牌主色选「天空蓝」呼应低空飞行意象,「活力橙」专用于抢单/报名/购买等高转化 CTA,实现「蓝=平台可信、橙=行动赚钱」语义分工。
- 接单 Tab 支持飞手/需求方双身份切换;合规引导(一登二查三申请 + 保险核验)设计为可复用步骤条组件,未完成硬性阻断履约打卡。
- 底部 TabBar 采用 5 项(首页/接单/学习/商城/我的),覆盖培训-考证-撮合-交易四大板块。

## 后续建议
- 按需扩展 B 端(企业/机构/商家/运营)后台规范,复用同一套 token。
- 配套高保真视觉稿:首页、订单广场、订单详情、考证报名、个人中心。
