# 毕数飞行平台 C端小程序 UI 设计规范

> 版本:v1.1 ｜ 编制:UI Designer ｜ 日期:2026-08-26 ｜ 适用范围:C端微信小程序(飞手 / 需求方 / 学员 / 消费者)
> 设计基准:375 × 812 逻辑像素(1px = 2rpx),组件级规范向下兼容 320px 小屏
> v1.1 变更:首页金刚区按产品评审基线由 8 宫格调整为 10 宫格(2 行 5 列),菜单清单见 5.1

---

## 1. 设计理念与原则

毕数飞行平台定位于「低空经济 · 无人机全生命周期服务生态」,承载培训、考证、撮合、交易四大板块。C端界面设计需同时满足两类用户的心智:

| 用户群 | 核心诉求 | 设计应对 |
|--------|----------|----------|
| 个人飞手(C端核心) | 免费学技能 → 考 CAAC → 合规接单赚钱 | 突出「接单变现」与「资质进度」,强化履约闭环 |
| 需求方/消费者 | 高效匹配合规运力、安全交易 | 突出「信任与保障」,合规凭证、保险、资金托管可视化 |

**四条设计原则:**

1. **专业可信优先** — 行业服务涉及资金托管、资质核验、合规履约,界面必须传递「安全、正规、有保障」的信任感,弱化促销喧嚣。
2. **任务驱动、少即是多** — 飞手的核心行为是「找到单 → 抢单 → 履约 → 收款」,首页与接单广场以「待办/机会」为主线,而非内容堆砌。
3. **合规显性化** — 「一登二查三申请」、保险核验、资质拦截不是隐藏的后台逻辑,而是以清晰的步骤引导、状态标签、风险提示显性呈现,让用户「知道该做什么、为什么被拦」。
4. **一致性优先于个性** — 全端统一设计 token 与组件,保证培训/考证/订单/电商四个板块的视觉与交互体验一致,降低学习成本。

## 2. 设计基础(Design Tokens)

### 2.1 色彩系统

色彩以「天空蓝」为品牌主色,呼应低空飞行意象;以「活力橙」作为「抢单/变现」等强行动 CTA 的强调色,形成「蓝=平台可信、橙=行动赚钱」的语义分工。

**品牌色**

| Token | 色值 | 用途 |
|-------|------|------|
| `--brand-primary` | `#1677FF` | 品牌主色:主按钮、选中态、链接、关键图标 |
| `--brand-primary-deep` | `#0958D9` | 主色深:按压态、强调文字 |
| `--brand-gradient` | `#1677FF → #00C2FF` | 品牌渐变:首页头图、主行动按钮、会员/认证标识 |
| `--brand-accent` | `#FF7A00` | 强调色(活力橙):「抢单/立即报名/立即购买」等高转化 CTA |
| `--brand-accent-deep` | `#E66A00` | 强调色按压态 |
| `--brand-teal` | `#00B578` | 辅助青绿:接单成功、资金到账、已验证等正向结果 |

**功能色(语义色)**

| Token | 色值 | 用途 |
|-------|------|------|
| `--color-success` | `#00B578` | 成功:支付成功、报名成功、核验通过 |
| `--color-warning` | `#FF8F1F` | 警告:待补充、风险提示、即将到期 |
| `--color-danger` | `#FA5151` | 危险:资质拦截、违约处置、扣分、封禁 |
| `--color-info` | `#1677FF` | 信息:提示、引导 |

**中性色**

| Token | 色值 | 用途 |
|-------|------|------|
| `--text-primary` | `#1A1A1A` | 主文本:标题、关键信息 |
| `--text-secondary` | `#595959` | 次文本:描述、次要信息 |
| `--text-tertiary` | `#8C8C8C` | 辅助文本:说明、时间戳 |
| `--text-disabled` | `#BFBFBF` | 禁用/占位 |
| `--border` | `#E5E6EB` | 边框、分割线 |
| `--divider` | `#F0F1F5` | 浅分割线、区块底色 |
| `--bg-page` | `#F5F6F8` | 页面背景 |
| `--bg-card` | `#FFFFFF` | 卡片/浮层背景 |

**配色规则:**
- 正文对比度 ≥ 4.5:1(`--text-primary` 于 `--bg-card` 上 ≈ 16.5:1,达标 WCAG AA)。
- 警示信息禁止仅靠颜色传达,必须叠加图标或文字标签(色弱友好)。
- 金额、佣金等数据用主文本色,涨/增用成功绿、跌/减用危险红,不用彩色底衬托。

### 2.2 字体系统

小程序统一使用系统字体栈,不引入第三方字体(保证加载速度与各机型渲染一致)。

```css
font-family: -apple-system, BlinkMacSystemFont, "PingFang SC",
             "HarmonyOS Sans SC", "Microsoft YaHei", sans-serif;
```

**字号阶梯(设计稿 375px)**

| 层级 | 字号 | 行高 | 字重 | 用途 |
|------|------|------|------|------|
| H1 大标题 | 20px | 28px | 600 | 页面主标题、金额主数 |
| H2 标题 | 17px | 24px | 600 | 卡片标题、区块标题 |
| H3 小标题 | 16px | 22px | 500 | 列表主标题、详情字段名 |
| Body 正文 | 15px | 22px | 400 | 正文、列表描述 |
| Caption 辅助 | 13px | 19px | 400 | 辅助说明、时间、标签 |
| Footnote 说明 | 12px | 17px | 400 | 角标、免责声明、占位 |
| 最小字号 | 11px | 16px | 400 | 仅限角标/水印 |

- 数字与金额建议使用 `tabular-nums`(等宽数字),避免跳动。
- 字重仅使用 **400 / 500 / 600** 三档,避免 700 以上带来的糊边。

### 2.3 间距系统(4px 基准)

所有间距取 4 的倍数,形成统一节奏。

| Token | 值 | 典型用途 |
|-------|----|----------|
| `--space-1` | 4px | 图标与文字最小间距、标签内边距 |
| `--space-2` | 8px | 组件内部紧凑间距 |
| `--space-3` | 12px | 列表项内间距、表单项间距 |
| `--space-4` | 16px | 卡片内边距、页面左右边距 |
| `--space-5` | 20px | 卡片间距、区块间距 |
| `--space-6` | 24px | 大区块间距、弹窗边距 |
| `--space-8` | 32px | 页面顶部留白 |
| `--space-10` | 40px | 首页头部、大型空态 |

- 页面统一左右安全边距 `--space-4`(16px)。
- 卡片列表纵向间距 `--space-3`(12px)。

### 2.4 圆角

| Token | 值 | 用途 |
|-------|----|------|
| `--radius-sm` | 4px | 角标、小标签 |
| `--radius-md` | 8px | 按钮、输入框、小卡片 |
| `--radius-lg` | 12px | 卡片、图片容器 |
| `--radius-xl` | 16px | 弹窗、大卡片、底部抽屉 |
| `--radius-full` | 999px | 胶囊按钮、标签、头像 |

### 2.5 阴影

小程序采用扁平化风格,弱化阴影,以背景色与边框区分层级。

| Token | 值 | 用途 |
|-------|----|------|
| `--shadow-card` | `0 2px 8px rgba(0,0,0,0.04)` | 悬浮卡片、吸顶栏 |
| `--shadow-float` | `0 8px 24px rgba(0,0,0,0.12)` | 弹窗、ActionSheet |

### 2.6 图标规范

- 线性图标,统一 **2px 描边**,圆角端点(round cap/join)。
- 尺寸:导航/金刚区 24px,列表功能 20px,行内辅助 16px。
- 图标需与文字语义一致,状态类图标(成功/警告/危险)必须与颜色 token 联动。

### 2.7 尺寸与单位

- 设计稿 375px,换算关系 **1px = 2rpx**;组件间距、字号用 rpx 保证跨机型等比缩放,1px 物理线用 `1px` 保真。
- 最小可点击热区 **44 × 44px(88rpx)**,列表行高 ≥ 48px(96rpx)。

## 3. 全局布局规范

### 3.1 页面骨架

```
┌──────────────────────────────┐
│ 状态栏 / 自定义导航栏(可选)   │
├──────────────────────────────┤
│                              │
│        内容滚动区            │
│   (背景 --bg-page)           │
│                              │
│                              │
├──────────────────────────────┤
│  TabBar(5项,仅一级页面)      │
└──────────────────────────────┘
```

- 页面背景统一 `--bg-page`(#F5F6F8),卡片内容承载在 `--bg-card` 上。
- 长列表页启用上拉加载、下拉刷新;空态/错误态/骨架屏三态必须完整。

### 3.2 导航规范

**底部 TabBar(5 项,一级入口)**

| Tab | 图标语义 | 定位 |
|-----|----------|------|
| 首页 | 房子 | 聚合导航 + 金刚区 + 推荐 |
| 接单 | 定位/雷达 | 订单广场(飞手视角)/需求发布(需求方视角),随角色切换 |
| 学习 | 书本/学位帽 | 技能培训 + CAAC考证 |
| 商城 | 购物袋 | 无人机整机/配件/二手 |
| 我的 | 人像 | 个人中心 |

- TabBar 选中态用 `--brand-primary`,未选中态用 `--text-tertiary`。
- 「接单」Tab 需支持飞手/需求方双身份切换(详见 5.2)。

**顶部导航栏**
- 默认使用小程序原生导航栏(标题居中),颜色跟随页面背景。
- 首页等沉浸式页面可自定义导航栏,背景用品牌渐变。

### 3.3 安全区适配

- 全面屏机型底部 TabBar 预留 `safe-area-inset-bottom`,内容区底部留白需叠加安全区。
- 顶部若有沉浸式头图,需处理刘海屏 `safe-area-inset-top`。

### 3.4 全局状态规范

| 状态 | 规范 |
|------|------|
| 加载中 | 骨架屏(优于全局 loading),首屏骨架屏占比 ≤ 1.5 屏 |
| 空态 | 统一空态插画 + 主文案 + 引导按钮(如「去发布需求」) |
| 错误态 | 错误插画 + 失败原因 + 「重试」按钮 |
| 无网络 | 顶部提示条 + 断网缓存数据展示 |
| 弱网/超时 | 操作按钮置灰防重复提交 + Toast 提示 |

## 4. 组件库规范

### 4.1 按钮 Button

| 变体 | 样式 | 用途 |
|------|------|------|
| 主按钮(Primary) | 品牌渐变底,白字,全圆角 | 页面级主操作:「立即报名」「提交需求」「确认支付」 |
| 强调按钮(Accent) | 活力橙底,白字,全圆角 | 高转化 CTA:「我要抢单」「立即购买」 |
| 次按钮(Secondary) | 白底 + 主色边框 + 主色字 | 次要操作:「联系客服」「查看详情」 |
| 幽灵按钮(Ghost) | 透明底 + 主色字 | 弱操作:「暂不」「取消」 |
| 危险按钮(Danger) | 危险红底或红字 | 「解除绑定」「申诉」「删除」 |
| 禁用态 | `--text-disabled` 字 + `--divider` 底 | 未满足前置条件(如资质未通过) |

- 尺寸:大 `44px`(主流程)、中 `36px`(卡片内)、小 `28px`(行内)。
- 主流程按钮固定底部吸底(叠加安全区),与内容区有 `--space-3` 分隔。
- 按钮文案用动词短语,≤ 6 字,语义明确(禁用时附禁用原因文字)。

### 4.2 标签 / 徽章 Tag / Badge

| 类型 | 样式 | 示例 |
|------|------|------|
| 状态标签 | 浅色底(色值 10% 透明度)+ 深色字 | 待付款/待接单/履约中/已完成/高风险 |
| 资质标签 | 品牌金底 + 白字,带图标 | 「民航认证飞手」「企业认证」 |
| 等级标签 | 渐变底 | 「银牌会员」「金牌会员」 |
| 数字徽章 | 危险红圆点/数字 | 消息未读、待办数 |

- 状态色映射:`待处理`=warning、`进行中`=info、`成功/已完成`=success、`失败/拦截/封禁`=danger、`高风险`=danger + 图标。

### 4.3 卡片 Card

- 基础卡片:白底、`--radius-lg`、`--shadow-card`、内边距 `--space-4`。
- 卡片标题区(标题 + 右侧更多/状态),内容区(信息 + 数据),底部操作区(按钮/价格)。
- 可点击卡片整卡热区,按压态背景 `--divider`。

**订单卡片(核心复用组件)** — 订单/接单/履约全流程统一结构:

```
[状态标签 ──────────── 订单编号]
[任务类型·机型·空域等级]
[📍 作业地点(地图缩略/文字)]
[🕐 时间 · 💰 报酬(主文本突出)]
────────────────────────
[信用/资质信息]   [主操作按钮]
```

### 4.4 列表 List

- 单项高度 ≥ 48px,左图标/头像 + 主标题 + 副标题 + 右侧状态/箭头。
- 分组列表用 `--divider` 浅底分隔,组间距 `--space-3`。
- 金额、关键数字右对齐,用主文本色 + `tabular-nums`。

### 4.5 表单 Form

| 元素 | 规范 |
|------|------|
| 输入框 | 高度 44px,`--radius-md`,聚焦边框变主色 + 1px 主色描边 |
| 文本域 | 最小 3 行,字数统计(右上角 12px 辅助色) |
| 选择器 | 右侧下箭头,点击弹底部 ActionSheet 或 picker |
| 单选/多选 | 22px,选中主色,热区 ≥ 44px |
| 开关 Switch | 主色,尺寸标准 51×31px |
| 校验 | 错误提示危险红,输入框描边危险红,行内提示 + 顶部 Toast |

- 表单标签左对齐,必填项加红色 `*`。
- 提交按钮统一吸底,点击后置灰防重复提交。

### 4.6 反馈 Feedback

| 组件 | 规范 |
|------|------|
| Toast | 居中,黑底白字 `--radius-md`,≤ 2 行,2s 自动消失;成功/失败可带图标 |
| Modal 弹窗 | `--radius-xl`,标题 + 内容 + 双按钮(次/主),危险操作主按钮用危险红 |
| ActionSheet | 底部弹出,选项 + 取消,危险项红字置顶 |
| Loading | 全局蒙层 + 文案 |

### 4.7 合规引导组件(平台特色)

「一登二查三申请」与保险核验需统一为可复用引导组件:

- **合规步骤条(Stepper)**:接单后履约前展示「①实名登记 → ②空域查询 → ③审批报备 → ④保险核验」,已完成打钩(青绿)、当前高亮(主色)、未完成置灰。
- **强制确认弹窗**:关键合规节点弹出,需勾选「我已确认并知晓」才可进入下一步,不可跳过。
- **风险提示条**:任务属管制空域/高风险时,详情页顶部常驻危险红提示条 + 免责声明链接。

### 4.8 数据展示

| 组件 | 规范 |
|------|------|
| 骨架屏 | 灰块 `--divider` 色,圆角与真实内容一致 |
| 空态 | 插画(240px 内)+ 主文案 + 引导按钮 |
| 数字滚动 | 金额、统计用 `tabular-nums` |
| 进度条 | 主色,用于学时进度、认证进度 |

## 5. 核心页面设计

### 5.1 首页

**定位**:聚合导航 + 角色化任务中心。用户打开即看到「我现在该做什么」。

**页面结构(自上而下)**:

```
[品牌渐变头图:搜索栏 + 定位城市 + 消息入口]
[身份切换:飞手 / 需求方 / 学员(胶囊切换)]
[金刚区 10 宫格:技能培训/CAAC考证/飞手登记/机器登记/
              需求发布/抢单大厅/二手交易/维修服务/
              线上商城/机器配件]
[我的待办(角色化):待接单/待履约/待付款/资质进度]
[Banner 轮播:平台活动/考证优惠/新机首发]
[推荐订单(飞手)/推荐服务(需求方)  瀑布流卡片]
[推荐课程 / 热销商品  横向滑动]
```

**要点**:
- 金刚区是五大板块的统一入口,图标 24px 线性 + 文字 12px,10 宫格每行 5 个;菜单清单与跳转目标如下:

| # | 菜单 | 图标语义 | 跳转 |
|---|------|----------|------|
| 1 | 技能培训 | 学士帽 | 学习中心(技能培训 Tab) |
| 2 | CAAC考证 | 执照/印章 | 学习中心(CAAC考证 Tab) |
| 3 | 飞手登记 | 人像 | UOM 飞手登记(二期) |
| 4 | 机器登记 | 芯片/序列 | UOM 机器登记(二期) |
| 5 | 需求发布 | 纸飞机 | 发布飞行需求(二级页) |
| 6 | 抢单大厅 | 闪电 | 接单广场(订单池) |
| 7 | 二手交易 | 购物车 | 商城(二手专区) |
| 8 | 维修服务 | 扳手 | 维修报修(二级页) |
| 9 | 线上商城 | 购物袋 | 商城(全新官方) |
| 10 | 机器配件 | 盒子 | 商城(配件类目) |

- 每宫格图标以「彩色渐变圆角底块(圆角约 26px)+ 图形」呈现,10 个宫格按 5+5 两行排布,底块色彩互不重复,保持 4px 间距体系。
- 「我的待办」依据身份动态渲染:飞手显示待抢单、待履约、资质核验状态;学员显示培训进度、待考证;需求方显示待验收、待付款。
- 未完成资质/实名/保险的用户,顶部显示常驻引导条(主色浅底):「完成认证,解锁接单赚钱」。

### 5.2 订单广场 / 需求发布(接单 Tab)

**定位**:撮合板块主战场,飞手找单、需求方发单。

**飞手视角 — 订单广场**:

```
[筛选:任务类型 / 区域 / 机型 / 执照等级(下拉筛选器)]
[订单卡片列表(见 4.3 订单卡片)]
  - 卡片底部:「我要抢单」(Accent 按钮)
  - 资质不符:按钮置灰 + 原因标签(如「需超视距执照」)
```

**需求方视角 — 需求发布**:

```
[任务信息表单:类型(多选)/ 地点(GPS打点+地图)/ 时间 / 预算 / 机型 / 执照要求]
[智能风险提示:空域属性预判(适飞/管制/禁飞) + 风险标注]
[确认发布(吸底主按钮) → 进入订单池]
```

**要点**:
- 双身份通过顶部胶囊 Tab 切换,记忆上次选择。
- 地图组件用于「打点选地点」,空域风险以红/黄/绿图钉或色块显性标注。
- 接单前资质校验拦截,弹窗说明「缺什么、怎么补」,并给出「去考证」「去认证」跳转。

### 5.3 订单详情与履约

**定位**:接单后到结算的全流程工作台,是合规引导的核心承载页。

**结构**:

```
[订单状态 + 状态进度条]
[任务信息卡片:类型/地点/时间/报酬/机型]
[双方信息:需求方(脱敏)/飞手(资质标签)]
[合规与保障区(步骤条):
  ①实名登记 ②空域查询 ③审批报备 ④保险核验]
[资金与合同:电子合同入口/资金托管状态]
[吸底操作区:当前阶段对应主按钮]
```

**履约阶段按钮流转**:联系需求方 → 确认接单 → 现场打卡 → 上传成果 → 等待验收 → 确认收款。

**要点**:
- 合规步骤条贯穿履约全程,未完成项硬性阻断「开始打卡」,并在按钮下方说明原因。
- 虚拟隐私号拨号、IM 客服入口、保单上传、UOM 凭证上传均在此页承载。
- 高风险订单全程顶部危险红提示条常驻。

### 5.4 学习中心(培训 + CAAC考证)

**定位**:技能培训(零费用)与 CAAC考证(付费)的统一入口,承接「培训 → 考证」转化漏斗。

**结构**:

```
[顶部切换:技能培训 / CAAC考证(胶囊 Tab)]
[筛选:工种方向 / 地区 / 机构 / 执照等级]
[课程卡片:封面图 + 机构认证标 + 课程名 +
          学时/开班时间 + 价格(免费=「免费」标签)]
[课程详情 → 报名]
```

**培训报名(零费用)流程要点**:
- 详情页突出「零费用学技能(人社补贴)」+ 补贴政策说明 + 受惠资格校验入口。
- 报名表单:身份信息(身份证 + 人脸核验)+ 就业状态,提交即报名,无支付环节。

**CAAC考证报名流程要点**:
- 详情页展示执照类型(视距内/超视距/教员)、机型、培训周期、费用、机构资质。
- 技能培训结业学员,自动触发「成长赋能弹窗」:提示考 CAAC 解锁接单,发放 500~1000 元专属抵用券。
- 收银台:报名费全额支付至资金监管账户,展示「证书回传后结算」说明。

### 5.5 商城

**定位**:无人机整机、配件、二手设备的交易入口。

**结构**:

```
[搜索 + 分类导航(整机/配件/载荷/二手/耗材)]
[Banner + 品牌专区]
[商品瀑布流卡片:图 + 标题 + 价格 + 标签(全新/二手/官方验机)]
[商品详情 → 下单]
```

**要点**:
- 商品卡片价格主文本突出,二手商品带「二手」「官方验机」标签,全新商品带「正品保障」标签。
- 二手商品详情页突出:SN 码防赃机核验标识、42 项验机报告入口、UOM 权属过户指引。
- 下单页含收货信息、配送/验机选项、优惠券、支付(资金监管托管)。

### 5.6 个人中心(我的)

**定位**:身份资产、履约信用、资金账户的总入口。

**结构**:

```
[头像 + 昵称 + 身份/等级标签 + 信用分(环形)]
[资质认证卡片:实名/CAAC执照/保证金/保险(进度 + 待办红点)]
[钱包:余额/待结算/保证金/提现(金额主文本突出)]
[我的订单:接单/发布/购买/培训/考证(横向入口)]
[常用:电子合同/客服/优惠券/积分/地址]
[信用分详情 + 成长等级 + 申诉入口]
```

**要点**:
- 信用分、认证状态、保证金是飞手核心资产,首屏高亮呈现。
- 待办统一以角标(危险红)聚合,点击跳转对应流程。
- 会员/等级用渐变标签,呼应商业权益(银牌/金牌)。

## 6. 关键交互流程规范

### 6.1 飞手接单流程

```
浏览订单广场 → 点击「我要抢单」
  → 资质校验(CAAC执照/机型/信用分/保证金)
     ├─ 不通过 → 拦截弹窗(说明缺什么 + 去补齐)
     └─ 通过 → 查看脱敏联系方式
  → 虚拟号沟通确认 → 签署电子合同
  → 需求方支付定金至监管账户
  → 合规步骤条:①实名登记 ②空域查询 ③审批报备 ④保险核验
  → 现场GPS打卡 → 上传成果 → 需求方验收 → 尾款结算
```

### 6.2 需求发布流程

```
填写任务信息 → 地图打点 + 空域风险预判提示
  → 确认发布(进入订单池) → 推送匹配飞手
  → 飞手接单 → 支付定金 → 履约 → 验收 → 支付尾款
```

### 6.3 技能培训报名流程(零费用)

```
浏览课程 → 详情(零费用+补贴政策说明)
  → 报名(身份核验 + 就业状态 + 补贴资格校验)
  → 报名成功(无支付) → 培训 → 结业考核 → 证书发放
```

### 6.4 CAAC考证报名流程

```
浏览考证班 → 详情(执照类型/费用/机构资质)
  → 报名(发放专属抵用券,如适用)
  → 收银台(全额支付至监管账户) → 培训考证 → 证书回传 → 解锁接单
```

### 6.5 UOM 合规引导(一登二查三申请)

```
接单后、起飞前强制流转:
① 实名登记(上传UOM登记码 + SN码核验)
② 空域查询(适飞/管制判断 + 强制勾选须知)
③ 审批报备(管制空域需上传UOM批文凭证)
④ 保险核验(平台一键投保 / 外部保单上传OCR核验)
→ 全部通过 → 解锁「开始作业打卡」
```

**规则**:任何一步未完成,「开始打卡」硬性阻断;高风险订单顶部常驻危险红提示;免责声明在发布与接单两处均需强制阅读确认。

## 附录 A:演示系统视觉扩展 token(v1.1)

> 适用范围:Web 高保真演示页(`演示系统/c-app.html`)与后续高保真视觉稿。
> **小程序生产环境仍以第 2 章为基线**(系统字体栈、扁平化、单阴影);本附录 token 属于演示层视觉增强,落地小程序时需降级为基线方案(如 Outfit 字体降级为系统 `tabular-nums`,渐变头图降级为 `--brand-gradient`)。

### A.1 天空网格渐变(头图氛围)

替代单一斜向品牌渐变,用于首页/个人中心头图、专题 Banner,营造「云端晴空」天光感:

```css
--sky-mesh:
  radial-gradient(120% 90% at 85% -10%, #69B4FF 0%, transparent 55%),
  radial-gradient(90% 70% at 8% 0%, rgba(0,194,255,.35) 0%, transparent 50%),
  linear-gradient(160deg, #0958D9 0%, #1677FF 55%, #3D9BFF 100%);
--teal-mesh:  /* 培训/补贴政策专题 */
  radial-gradient(110% 80% at 88% -8%, #5FE3B3 0%, transparent 55%),
  linear-gradient(150deg, #00875A 0%, #00B578 60%, #1FC98C 100%);
--navy-mesh:  /* CAAC考证/成长通道专题 */
  radial-gradient(110% 85% at 85% -10%, #4E7FD9 0%, transparent 55%),
  linear-gradient(155deg, #14295C 0%, #1F3B7A 55%, #2B56A8 100%);
```

### A.2 数字展示字体

- 金额、价格、信用分等关键数字使用 **Outfit**(Google Fonts,仅拉丁+数字子集,600/700 两档),配合 `tabular-nums`,强化数据感。
- 中文与正文仍使用第 2.2 节系统字体栈;小程序端降级为系统字体 + `tabular-nums`。

### A.3 纹理与装饰

- **噪点层**:SVG `feTurbulence` data-URI,opacity ≤ 0.06,叠加于头图/深色 Banner(`mix-blend-mode: overlay`),增加质感。
- **等高线/航线装饰**:低透明度(0.10–0.28)白色 SVG 路径,仅用于品牌渐变头图,呼应低空飞行意象,不承载信息。

### A.4 海拔阴影阶梯

替代单一 `--shadow-card`,按悬浮层级递进(仍以扁平为主,阴影克制):

| Token | 值 | 用途 |
|-------|----|------|
| `--elev-1` | `0 1px 2px rgba(15,42,90,.04), 0 4px 14px rgba(15,42,90,.06)` | 常规卡片 |
| `--elev-2` | `0 6px 20px rgba(15,42,90,.10)` | 上叠浮卡、Banner |
| `--elev-3` | `0 12px 32px rgba(15,42,90,.14)` | 弹窗、抽屉 |

### A.5 动效 token

| Token | 值 | 用途 |
|-------|----|------|
| `--ease` | `cubic-bezier(0.16, 1, 0.3, 1)` | 统一缓动(回弹克制的 expo-out) |
| 页面切换 | fade + 10px 上浮,300ms | Tab/二级页进场 |
| 错峰入场 | 卡片依次延迟 60–100ms | 首屏信息编排,仅首屏 |
| 按压反馈 | `transform: scale(.96)`,150ms | 按钮/可点卡片 |
| 步骤条当前节点 | 主色脉冲光环 2s infinite | UOM 合规步骤条当前步骤 |

### A.6 玻璃拟态(仅限品牌头图内)

头图内搜索栏、身份切换器使用 `rgba(255,255,255,.16)` 底 + `backdrop-filter: blur(10px)` + 1px 半透明白描边;**内容区卡片不使用玻璃拟态**,保证信息可读性。
