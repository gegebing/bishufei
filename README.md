# 毕数飞行平台 - 项目工作区目录说明

本工作区已按照功能与成果划分为两大标准目录：

```
d:/work/bishufei/
├── 📁 演示系统/               # 多端高保真交互演示版 HTML 原型
│   ├── index.html            # 🌐 统一演示导航门户 (入口)
│   ├── c-app.html            # 📱 C端微信小程序交互原型
│   ├── b-training.html       # 🏫 B端培训机构管理后台
│   ├── b-enterprise.html     # 🏢 B端用机企业/机组管理后台
│   └── b-admin.html          # 🛡️ B端综合运营与风控中枢
│
└── 📁 设计文档/               # 系统架构方案与 UI 设计规范
    ├── 毕数飞行平台系统设计方案_V2.0_最新.docx   # 最新版完整系统设计方案
    ├── 毕数飞行平台系统设计方案_V2.0.docx
    ├── 毕数飞行平台系统设计方案_V1.0.docx        # 历史版本对照
    └── 毕数飞行平台_C端小程序UI设计规范.md      # C端小程序设计规范
```

---

### 快速开始体验
直接进入 `📁 演示系统/` 文件夹，双击打开 **`index.html`** 即可在浏览器中体验全套多端交互演示系统！
