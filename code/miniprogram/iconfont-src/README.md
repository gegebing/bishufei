# 阿里 iconfont 接入指南

## 为什么用阿里 iconfont
金刚区原用 emoji 在不同机型渲染风格不一致、显廉价(AI 感)。替换为阿里 iconfont 字体图标后配色统一、线条精致,并支持任意颜色/尺寸。

## 操作步骤

1. **选图标**:打开 https://www.iconfont.cn —— 搜索下面关键词,逐个加入购物车(统一选**线性/单色**风格,推荐「单色线性」类型):

| 金刚区入口 | iconfont 搜索关键词 |
|-----------|--------------------|
| 技能培训 | 学士帽 / 培训 |
| CAAC考证 | 证书 / 执照 |
| 飞手登记 | 用户 / 人像 |
| 机器登记 | **无人机**(项目推荐给到的即此款) |
| 需求发布 | 纸飞机 / 发布 |
| 抢单大厅 | 闪电 / 抢单 |
| 二手交易 | 购物车 / 二手 |
| 维修服务 | 扳手 / 维修 |
| 线上商城 | 购物袋 / 商城 |
| 机器配件 | 盒子 / 配件 |

2. **建项目生成字体**:
   - 右侧购物车 → 「添加至项目」→ 新建项目(如:毕数飞行平台)
   - 项目页 →「生成代码」→ 选 **Font class** → 下载 ZIP 源码包(也可点「复制代码」把生成的 CSS/Unicode 保存)

3. **解压放进来**:`iconfont.css` 和 `iconfont.ttf` 放到本目录(iconfont-src/)

4. **对类名**:看图标的实际类名(iconfont.css 里显示为 `.icon-xxx`),修改本目录 `map.mjs` 的类名(不填也行,脚本会尝试按 map.mjs 里的默认值匹配)

5. **生成**:
   ```
   node scripts/gen-iconfont.mjs
   ```
   输出 `src/styles/iconfont.scss`,首页金刚区自动切换为字体图标(mapping 缺失时自动回落 emoji,不破版)

## 注意
- 微信小程序**不支持**网络字体和外链 CSS,所以用 base64 内嵌(10 个图标约 10~30KB,体积可控)
- 若业务增加图标,继续 iconfont 加图标 → 重新下载 → 再跑脚本即可
- 依赖 Node 18+(使用 ESM)
